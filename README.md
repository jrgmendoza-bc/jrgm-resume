# Jervin Ryan Mendoza: Resume & Portfolio

Live site: https://jrgmendoza-bc.github.io/jrgm-resume/

A single self-contained `index.html` (no build step): portfolio, project gallery and a printable one-page resume.
Use the "Save resume as PDF" button on the site to export the resume.

Edit the contact details and photo in the `CONFIG` block near the bottom of `index.html`.
